# Trigger.dev Tasks

Durable background jobs for Ghost AI live in this directory.

Local development requires:

- `TRIGGER_PROJECT_ID`: Trigger.dev project ref from the dashboard.
- `TRIGGER_SECRET_KEY`: development secret key from the Trigger.dev project API keys page.

Run tasks locally with:

```bash
npm run trigger:dev
```

Deploy tasks with:

```bash
npm run trigger:deploy
```
